# ae-video

Плагин для [Claude Code](https://claude.com/claude-code), который превращает запись вашего голоса в анимированное видео в Adobe After Effects.

Вы говорите, а агенты делают рутину: расшифровывают речь с точностью до слова, вместе с вами планируют анимацию, собирают её из готовых блоков и привязывают к словам. Всё, что создаёт плагин, остаётся обычными слоями и ключами After Effects: любую деталь можно поправить руками.

Плагин подходит для обучающих и объясняющих роликов. Он работает локально на вашем Mac: запись голоса никуда не отправляется, расшифровка идёт на вашем компьютере.

## Что нужно

| Что | Зачем | Как получить |
|---|---|---|
| Mac на Apple Silicon (M1 и новее) | Расшифровка через MLX работает только на нём | — |
| Adobe After Effects | Сборка видео. Плагин проверялся на версии 2026 | [Creative Cloud](https://www.adobe.com/products/aftereffects.html) |
| Claude Code | В нём работают агенты плагина. Нужна учётная запись Claude с доступом к Claude Code | [Инструкция по установке](https://code.claude.com/docs) |
| Python 3.9 или новее | Скрипты плагина | Обычно уже есть: проверьте `python3 --version` |
| ffmpeg | Работа со звуком и кадрами | `brew install ffmpeg` |
| Шрифты Golos Text и JetBrains Mono | Шрифты стартовой базы | [Golos Text](https://fonts.google.com/specimen/Golos+Text), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) |

На диске понадобится около 2 ГБ: при первой расшифровке скачивается модель распознавания речи.

## Установка

Команды выполняются в Терминале.

**1. Подключите каталог плагина:**

```bash
claude plugin marketplace add bogdannovikov1/ae-pipeline-plugin
```

**2. Установите плагин:**

```bash
claude plugin install ae-video@ae-video-marketplace
```

**3. Установите библиотеки Python:**

```bash
pip3 install mlx-whisper numpy
```

**4. Настройте After Effects.** Откройте After Effects, затем `Settings > Scripting & Expressions` и включите **Allow Scripts to Write Files and Access Network**. Без этого скрипты не смогут сохранять результат. На английском интерфейсе пункт называется именно так, на других языках название будет переведено.

**5. Откройте новую сессию Claude Code,** чтобы плагин загрузился.

Чтобы обновить плагин позже:

```bash
claude plugin update ae-video@ae-video-marketplace
```

## Первая настройка

В Claude Code выполните:

```text
/ae-video:setup
```

Команда создаст рабочую базу в `~/Documents/ae-video/bases/starter` и проверит компьютер: Python, ffmpeg, библиотеки, After Effects и шрифты. Если чего-то не хватает, она скажет, что сделать.

Если у вас другая версия After Effects, укажите её название, как оно написано в папке «Программы». Создайте файл `~/.config/ae-video/settings.json`:

```json
{
  "ae": { "app": "Adobe After Effects 2025" }
}
```

## Первое видео шаг за шагом

Для первого раза возьмите запись на 30–60 секунд.

**Шаг 1. Запишите голос и положите файл на место.** Подойдут WAV, MP3, M4A, AIF. Создайте папку видео и фрагмента. Фрагмент — это часть ролика со своей композицией. Файл называется так же, как папка фрагмента:

```text
~/Documents/ae-video/videos/my_first_video/fragments/F1/F1.wav
```

**Шаг 2. Запустите плагин:**

```text
/ae-video:make ~/Documents/ae-video/videos/my_first_video F1
```

Дальше плагин ведёт вас сам и говорит, что нужно от вас. Вот что будет происходить.

**Шаг 3. Транскрипт.** Плагин спросит о терминах и именах в записи и о частоте кадров. Он расшифрует речь локально. Первый запуск скачает модель и займёт несколько минут. Затем он покажет сомнительные слова.

**Шаг 4. Ревью транскрипта в After Effects.** Плагин спросит, открыть ли After Effects: без вашего согласия он его не запускает. В проекте будет дорожка голоса с маркером на каждое слово, красным помечены сомнительные. Поправьте текст и положение маркеров, лишние удалите, недостающие добавьте. Скажите в чате, что закончили: плагин заберёт правки и заморозит транскрипт. Дальше анимация опирается на номера слов, поэтому после заморозки текст не меняется случайно.

**Шаг 5. План анимации.** Вместе с плагином вы решаете, что показывать на каких словах. Он предложит таблицу из блоков базы. Для каждого момента выбираете вы: взять готовый блок или сделать новый.

**Шаг 6. Сборка.** Агент `animator` собирает сцену, проверяет её скриптами и строит композицию в After Effects. Анимация идёт параллельно речи и начинается немного раньше слова.

**Шаг 7. Предревью, по желанию.** Плагин спросит, нужно ли оно. Агент `reviewer` снимает кадры и сверяет их с законами монтажа и вашей базой. Это самый дорогой этап по токенам, поэтому он никогда не запускается сам и спрашивает перед каждым кругом.

**Шаг 8. Доводка.** Дорабатывайте композицию в After Effects руками или просите правки в чате. Сохраните проект как `F1.aep` и подтвердите этап. После доводки плагин не пересобирает сцену без вашего решения: ручные правки не потеряются.

**Шаг 9. Обновление базы, по желанию.** Плагин спросит, нужно ли обновлять базу. Если нет, этап пропускается и токены не тратятся. Если да, он предложит, что стоит добавить из этой работы, и запишет только то, что вы выбрали.

**Шаг 10. Следующая запись.** Плагин спросит, расширить текущий фрагмент или начать новый. Связанный материал лучше дописать в тот же фрагмент, новая логическая часть начинает новый. Экспорт и склейку фрагментов пока делайте вручную в After Effects или другом редакторе.

Работу можно прервать в любой момент. Состояние хранится в файлах: вызовите `/ae-video:make` с теми же аргументами в новой сессии, и плагин продолжит с того же места.

## Команды

| Команда | Что делает |
|---|---|
| `/ae-video:setup` | Первая настройка и проверка компьютера |
| `/ae-video:make <папка видео> <фрагмент>` | Ведёт видео по всем этапам, главная команда |
| `/ae-video:transcript <запись или папка видео и фрагмент>` | Транскрипт и ревью |
| `/ae-video:plan <папка видео> <фрагмент>` | План анимации по транскрипту |
| `/ae-video:animate <папка видео> <фрагмент> [что сделать]` | Сборка или правка анимации |
| `/ae-video:review <папка видео> <фрагмент> [с какой секунды]` | Разовое ревью монтажа |
| `/ae-video:base <что сделать>` | Добавить, изменить, удалить или найти что угодно в базе |

Отдельные команды соблюдают тот же порядок, что и `make`: например, план нельзя составить без утверждённого транскрипта.

Примеры:

```text
/ae-video:animate ~/Documents/ae-video/videos/my_first_video F1 сделай заголовок крупнее
/ae-video:review ~/Documents/ae-video/videos/my_first_video F1 12
/ae-video:base добавь звук ~/Downloads/click.wav как звук появления объекта
```

## База: ваш почерк

База — папка с вашим стилем: принципы, цвета, шрифты, блоки анимации, звуки и картинки. Благодаря ей все ролики выглядят как один канал, а агенту не приходится изобретать стиль заново.

```text
bases/starter/
  base.json            паспорт базы
  style.md             кто вы: идея, голос, зритель, запреты
  craft.md             как исполнять стиль: ваши правила монтажа
  tokens.json          числа: цвета, шрифты, размеры, тайминги, звуки
  blocks/              блоки анимации: код и описание
  assets/              картинки, видео, звуки
  assets/assets.json   описания ассетов
  references/          образцы
```

Стартовая база содержит 26 блоков: массивы, карточки, лента памяти, код, формулы, текст, стрелки, фон. Звуков и картинок в ней нет. Блоки `fly_asset`, `object_pop` и `asset_value` заработают после того, как вы добавите свои ассеты, а звуковые эффекты — после того, как вы укажете их в `tokens.json`.

Звуки событий задаются в `tokens.json`, в разделе `sounds`: появление объекта, группа, стрелка, перелёт, обмен, выделение. Список `appear` выбирает звук появления по его длительности: быстрый, средний, выше среднего. Звук ставится так, чтобы он заканчивался вместе с анимацией. Добавляйте звуки через `/ae-video:base`.

Что сделать сначала:

1. Заполните `style.md` и `craft.md`: сейчас это шаблоны. Проще всего описать свой стиль словами через `/ae-video:base`.
2. Поменяйте цвета и шрифты через ту же команду.
3. Добавьте свои звуки и картинки.

Меняйте базу через `/ae-video:base`: агент держит файлы согласованными и спрашивает подтверждение. Базу удобно хранить в своём git-репозитории. Подробности: [docs/base.md](docs/base.md).

Законы, общие для любых авторов, лежат не в базе, а в плагине: монтаж, композиция, цвет, типографика, движение, звук. При конфликте главнее ваше решение, затем база, затем общие законы.

## Как работают этапы

| Этап | Кто делает | Результат | Ваше участие |
|---|---|---|---|
| Транскрипт | Агент `transcriber` | `F1.timeline.json`, `F1.notes.md`, `F1.aep` | Правите маркеры в After Effects |
| План | Оркестратор в диалоге | `F1.animation.json` | Выбираете блоки в чате |
| Сборка | Агент `animator` | `F1.scene.json`, композиция | — |
| Предревью | Агенты `reviewer` и `animator` | `reviews/round_N.json` | Разрешаете каждый запуск |
| Доводка | Вы и `animator` | `F1.aep` | Дорабатываете и подтверждаете |
| Обновление базы | Агент `librarian` | `F1.base_proposals.md` | Решаете, нужен ли этап, и выбираете, что записать |

Каждый этап получает файлы и отдаёт файлы, поэтому следующий этап можно запускать в новой сессии. Если изменить файл, этапы, которые от него зависят, помечаются устаревшими. Состояние лежит в `state.json` в папке фрагмента, менять его руками не нужно.

Папка видео выглядит так:

```text
my_first_video/
  settings.json          необязательные настройки этого видео
  fragments/
    F1/
      F1.wav             запись
      F1.timeline.json   транскрипт
      F1.animation.json  план
      F1.scene.json      сцена
      F1.aep             проект After Effects
      state.json         состояние этапов
      reviews/           отчёты ревью
      frames/            кадры для ревью
      blocks/            блоки, написанные только для этого видео
```

## Настройки

Настройки накладываются слоями, каждый следующий главнее:

1. Значения по умолчанию внутри плагина.
2. Ваши личные: `~/.config/ae-video/settings.json`.
3. Настройки одного видео: `<папка видео>/settings.json`.

В файле нужно указать только то, что меняете:

```json
{
  "bases_dir": "~/Videos/bases",
  "base": "my_channel",
  "review": { "max_rounds": 2 },
  "timing": { "max_early": 0.3 }
}
```

Часто нужные настройки:

| Ключ | Значение | По умолчанию |
|---|---|---|
| `bases_dir` | Папка с базами | `~/Documents/ae-video/bases` |
| `base` | Активная база | `starter` |
| `transcribe.language` | Язык записи | `ru` |
| `ae.app` | Название After Effects | `Adobe After Effects 2026` |
| `ae.autosave_projects` | Папки, где проект можно сохранять без вопроса | пусто |
| `review.max_rounds` | Максимум кругов предревью | `3` |
| `base_update.every_fragments` | Как часто спрашивать про обновление базы; 0 отключает | `1` |

Полный список: [docs/settings.md](docs/settings.md). Цвета, тайминги анимации и шрифты задаются не здесь, а в `tokens.json` базы.

## Как тратятся токены

Плагин использует токены вашего Claude только там, где нужны вкус и смысл. Расшифровка, проверки, сборка и сбор фактов идут скриптами.

- Самый дорогой этап — `reviewer`: он смотрит кадры. Он никогда не запускается без вашего согласия.
- `animator` работает с текстом и данными. Картинки он смотрит, только если вы сами попросили скрины в запросе.
- Агенты читают короткие текстовые виды, а не большие файлы.
- Длинное видео дешевле делать по фрагментам в отдельных сессиях.

## Решение проблем

| Что случилось | Что делать |
|---|---|
| Команд `/ae-video:...` нет | Откройте новую сессию Claude Code. Проверьте: `claude plugin list` |
| `Allow Scripts to Write Files`, файл не записан | Включите настройку из шага 4 установки и повторите команду |
| `After Effects не запущен` | Плагин ждёт вашего согласия: разрешите запуск в чате |
| Не удалось запустить After Effects | Укажите в настройках точное название приложения: `ae.app` |
| `The open project has unsaved changes` | Сохраните открытый проект в After Effects и повторите. Плагин не трогает чужие несохранённые проекты |
| Вместо шрифта стоит другой | Установите шрифты базы и перезапустите After Effects |
| `mlx_whisper` не найден | Выполните `pip3 install mlx-whisper numpy` тем же `python3`, который используется в Терминале |
| Первая расшифровка идёт долго | Скачивается модель, около 1,6 ГБ. Следующие запуски будут быстрее |
| Неточные таймкоды слов | Поправьте маркеры на ревью. Распознавание даёт приблизительное положение |
| Этап помечен устаревшим | Изменился файл, от которого он зависит. Вызовите `/ae-video:make`: плагин скажет, что дальше |
| Передумали расширять фрагмент | Попросите отменить расширение: плагин вернёт файлы и этапы к прошлому состоянию |
| Проверить всё разом | `/ae-video:setup` |

## Ограничения

- Только macOS на Apple Silicon: запуск After Effects идёт через AppleScript, распознавание через MLX.
- Движение и звук агенты не оценивают: кадры показывают только отдельные моменты. Финальное решение всегда за вами.
- Склейка фрагментов в одно видео пока не автоматизирована.
- После ручной доводки новая часть не может анимировать объекты из старой части: плагин предложит создать их заново или пересобрать всё.
- Интерфейс агентов и инструкции написаны на русском.

В планах: агенты для режиссуры, склейки и перевода на другие языки. Подробнее: [PLAN.md](PLAN.md).
