# База

База — это почерк автора в файлах: его принципы, вкус, приёмы и материалы. Плагин знает, как монтировать вообще, база знает, как монтирует именно этот автор. Благодаря ей все ролики выглядят как один канал, а агент не изобретает стиль заново и тратит меньше токенов.

База живая. Каждый ролик может дать ей новый приём, правило или звук, а что-то устаревает. Она лежит в папке `bases_dir/<имя>/` и может иметь свой git, поэтому переносится и версионируется отдельно от плагина. Баз может быть несколько: активная задаётся настройкой `base`.

Плагин приносит `plugin/starter_base`: блоки и токены без ассетов и шаблоны `style.md` и `craft.md`. Команда `/ae-video:setup` копирует её в рабочую папку, и дальше база принадлежит автору.

## Устройство

```text
<имя базы>/
  base.json            паспорт: имя, версия, пути к частям
  style.md             кто автор: идея, голос, зритель, цель, запреты, образцы
  craft.md             как исполнять стиль: режиссура, синхрон, цвет, движение, звук, чек-лист
  tokens.json          числа стиля: цвета, шрифты, размеры, тайминги, кривые, звуки
  blocks/<id>/
    block.jsxinc       код анимации
    block.json         описание, параметры, когда применять
  assets/              картинки, видео, звуки
  assets/assets.json   описание каждого ассета
  references/          кадры и видео, на которые равняемся
```

## Звуки

Звуки настраиваются в разделе `sounds` файла `tokens.json`:

```json
{
  "level": -14,
  "pop": "звук появления",
  "group": "звук группы",
  "arrow": "звук стрелки",
  "move": "звук перелёта",
  "swap": "звук обмена",
  "highlight": "звук выделения обводкой",
  "scan": "звук выделения заливкой",
  "text": null,
  "appear": [
    { "max": 0.5, "sound": "быстрый" },
    { "max": 1.0, "sound": "средний" },
    { "sound": "выше среднего" }
  ],
  "levels": { "scan": -20 }
}
```

`null` отключает звук события. Если есть `appear`, появление объекта и группы выбирает звук по длительности анимации. `level` задаёт общую громкость в децибелах, `levels` исключения: минус 6 дБ это вдвое тише. Отдельный элемент сцены отключается параметром `sound: false`. После добавления файла `librarian` измеряет его слышимую длину `audible`.

## Куда что записывать

| Что появилось | Куда |
|---|---|
| Число или цвет | `tokens.json` |
| Правило исполнения | `craft.md` |
| Вкус и принципы автора | `style.md` |
| Повторяющийся приём | блок в `blocks/` |
| Файл-материал | `assets/` и запись в `assets.json` |
| Образец | `references/` |
| Закон, верный для любого автора | основы монтажа плагина, не база |

Приоритет при конфликте: решение автора, `style.md` и `craft.md`, основы монтажа.

## Как база меняется

Только через агента `librarian`. Он знает устройство базы целиком (навык `base-structure`) и может добавить, изменить или удалить любую её часть. Всё начинается с подтверждения автора, заканчивается проверкой целостности и коммитом.

Два пути:

- **По просьбе автора:** в любой момент.
- **Этап `curate`:** раз в `base_update.every_fragments` фрагментов плагин спрашивает, нужно ли обновление. Если нет, этап пропускается и токены не тратятся. Если да, скрипт `base_scan.py` без модели собирает факты: блоки вне базы, повторяющиеся находки предревью, токены, которые часто меняют в сценах, заметки автора. `librarian` превращает их в список предложений, автор выбирает, в базу попадает только выбранное.
