name: plan
description: Составляет с автором план анимации по замороженному транскрипту. Отдельная команда автора, этап plan конвейера.
argument-hint: "<папка видео> <фрагмент>"
disable-model-invocation: true
---

Автор запросил план анимации: $ARGUMENTS.

1. Проверь состояние: `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/pipeline.py next <видео> <фрагмент>`. Для плана транскрипт должен быть утверждён. Если он не готов, скажи об этом и предложи `/ae-video:transcript`. Если план уже утверждён, предупреди, что сцена и доводка после него устареют, и спроси, менять ли его.
2. Вызови `start plan`.
3. Покажи текст: `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/view.py text <транскрипт>`. Блоки и ассеты: `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/base_index.py`. JSON транскрипта не читай. Прочитай `style.md` и `craft.md` базы один раз.
4. Предложи биты таблицей: слова, что показываем, блок. Вопросы задавай пачкой, а не по одному.
5. Для каждого бита без подходящего блока автор выбирает: ближайший готовый или новый блок. Сам не решай.
6. Привязывай биты к словам по правилу `learn.anchor`: шагами по речи, а один объект на длинную фразу к смысловому слову в зоне опоры.
7. Запиши `<фрагмент>.animation.json` с `transcript_hash` из транскрипта: `python3 ${CLAUDE_PLUGIN_ROOT}/scripts/view.py hash <транскрипт>`. Формат: `at_word`, `until_word`, `intent`, `block`, `params`.
8. Вызови `done plan`. После подтверждения автора: `approve plan`.

Если в `next` есть `extension`, старые биты не меняй: новые добавляй в конец, начиная со слова `extension.first_word`, и обнови `transcript_hash`.

Следующая команда: `/ae-video:animate`.
