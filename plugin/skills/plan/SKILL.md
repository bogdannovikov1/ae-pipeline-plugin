Автор запросил план анимации: $ARGUMENTS. Ты ведёшь этот диалог сам. Ниже `S` — `${CLAUDE_PLUGIN_ROOT}/scripts`.

План — единственная постановка для аниматора. Чего нет в файле плана, того не будет в сцене.

1. **Состояние.** `python3 S/pipeline.py next <видео> <фрагмент>` → JSON. Для плана транскрипт должен быть утверждён. Не готов — скажи и предложи этап транскрипта. План уже утверждён — предупреди, что сцена и доводка после него устареют, и спроси, менять ли его.
2. **`start plan`** → JSON без «Отказ».
3. **Материал.** Текст: `python3 S/view.py text <транскрипт>`. Блоки и ассеты: `python3 S/base_index.py`. JSON транскрипта не читай. Прочитай `style.md` и `craft.md` базы один раз (папка: `python3 S/brief.py env`).
4. **Биты.** Предложи таблицей: id, слова, что показываем, блоки. Вопросы задавай пачкой, а не по одному.
5. **Блоки.** Для каждого бита без подходящего блока автор выбирает: ближайший готовый или новый блок. Сам не решай. Если приём состоит из нескольких блоков (массив, заливка, указатель), перечисли их все.
6. **Якоря.** Привязывай биты к словам по правилу `learn.anchor`: шагами по речи, а один объект на длинную фразу — к смысловому слову в зоне опоры.
7. **Файл.** Запиши `<фрагмент>.animation.json`:
   - `transcript_hash`: вывод `python3 S/view.py hash <транскрипт>`;
   - у каждого бита: `id` (короткий, уникальный), `at_word`, `until_word`, `intent`, `blocks` — все утверждённые блоки бита, `block` — главный из них, `params` — данные и числа, которые назвал автор;
   - всё, что автор уточнил (данные, порядок, цвета словами, ограничения вида «не заменять X»), впиши в `intent` или `params` этого бита. Устные договорённости вне файла не существуют.

   ```json
   { "id": "scan", "at_word": 20, "until_word": 24, "intent": "Перебор слева направо, остановка на найденном", "block": "pointer_move", "blocks": ["pointer_move", "fill_cells"], "params": { "sequence": [0, 1, 2] } }
   ```
8. **Проверка.** `python3 S/validate.py animation <план>` → «Проверка пройдена». Затем `done plan`. Покажи автору итоговую таблицу. После его явного «да»: `approve plan`.

Если автор после утверждения что-то уточняет, сначала впиши это в план, снова пройди шаг 8 и только потом передавай сборку.

Если в `next` есть `extension`, старые биты не меняй: новые добавляй в конец, начиная со слова `extension.first_word`, и обнови `transcript_hash`.

Следующая команда: `/ae-video:animate` (в других моделях `brief.py animate <видео> <фрагмент>`).
