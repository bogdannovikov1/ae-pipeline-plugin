База — это почерк автора в файлах. Она отвечает на вопрос «как делает именно этот автор» и постоянно растёт из его работы. Всё общее для любых авторов живёт в основах монтажа плагина, всё личное здесь.

## Файлы

| Путь | Что хранит | Когда меняется |
|---|---|---|
| `base.json` | Паспорт: имя, версия, пути к частям базы | При смене структуры |
| `style.md` | Кто автор, идея, голос, зритель, цель, запреты, образцы | Изменился почерк |
| `craft.md` | Как исполнять стиль: режиссура, синхрон, композиция, цвет, движение, звук, чек-лист | Найден новый приём или правило |
| `tokens.json` | Числа стиля: цвета, шрифты, размеры, тайминги, кривые, звуки | Изменилось значение |
| `blocks/<id>/block.jsxinc` | Код анимации | Новый или улучшенный приём |
| `blocks/<id>/block.json` | Описание, параметры, когда применять | Вместе с кодом |
| `assets/` | Картинки, видео, звуки | Новые материалы |
| `assets/assets.json` | Описание каждого ассета | Вместе с файлами |
| `references/` | Кадры и видео, на которые равняемся | Новый образец |

## Форматы

Запись ассета: `id`, `file`, `type`, `group`, `description`, `tags`, `source`, `license`. Описание пишется так, чтобы по нему другой агент понял, когда ассет подходит.

Блок вызывается движком: получает `params`, время начала, `id` и элемент сцены, возвращает созданные слои. Значения стиля берёт из `Engine.tokens`, а не из кода. Примеры лежат рядом в `blocks/`.

## Куда что записывать

- Число: в `tokens.json`, а не в код блока или текст.
- Правило исполнения: в `craft.md`.
- Вкус и принципы автора: в `style.md`.
- Повторяющийся приём: в блок.
- Закон, верный для любого автора: это основы монтажа плагина, а не база.

Одно правило живёт в одном месте. Если новое правило спорит со старым, предложи автору заменить старое.

## Проверка целостности

1. У каждой записи `assets.json` есть файл, у каждого файла есть запись, все `id` уникальны.
2. У каждого блока есть `block.jsxinc` и `block.json`.
3. Токены, на которые ссылаются блоки, существуют.
4. Удаляемый элемент не используется в блоках базы.
5. `style.md` и `craft.md` не противоречат друг другу.
6. Изменения закоммичены в git базы.
