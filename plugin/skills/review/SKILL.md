argument-hint: "[папка видео] [фрагмент] [с какой секунды]"

Автор сам попросил ревью: $ARGUMENTS.

1. Узнай папку фрагмента и какой отрезок смотреть. Если автор дал отрезок, используй его как `from_time`.
2. Выбери следующий свободный номер N для `reviews/manual_N.json`.
3. Запусти агента `reviewer` один раз. Передай сцену, путь отчёта, `from_time` и метку кадров `manual_N`: он снимает кадры с `--label manual_N`, а при открытом проекте сцена уже собрана. Если автор доводил сцену вручную, скажи об этом агенту: правки автора не считаются ошибками.
4. Покажи находки и что не проверено. Больше ничего не запускай.

Состояние этапов это ревью не меняет. Исправления делает `animator` только по просьбе автора, а второе ревью — только по новой просьбе.
