# Ловушки After Effects при написании блока

Собрано на реальных сборках. Читай перед тем, как писать или править `block.jsxinc`.

## ExtendScript

- Это ES3: без `JSON`, `let`, `const`, стрелочных функций, шаблонных строк, `Array.prototype.map/forEach/indexOf`.
- В тексте выражения массив, склеенный со строкой (`"[" + arr + "]"`), может упасть с «invalid numeric result». Собирай строку явно: `"[" + arr[0] + "," + arr[1] + "]"`.
- Модальное окно AE останавливает автоматизацию. Пробные скрипты оборачивай в `try/catch` и пиши результат в файл, а не в `alert`.

## Свойства и слои

- **`addProperty` портит соседние ссылки.** После добавления обрезки, заливки, обводки или новой группы ранее сохранённые ссылки на свойства той же группы становятся невалидными («Object is invalid»). Храни слой и бери свойства заново по имени группы и match name перед каждым использованием, в том числе в замыканиях. Удобно сначала построить всю структуру, а потом анимировать.
- **Родитель до позиции.** Сначала `parent`, потом позиция в координатах родителя (помощник движка, если он есть: `Engine.attach`). Позиция, заданная до родителя, может удвоиться, если родитель в этот момент сдвинут или анимирован.
- **2D и 3D значения не смешивай.** Ключ `[x, y]` на 3D-свойстве даёт `NaN`: недостающий компонент бери из текущего значения.
- Match name с опечаткой AE: скругление звезды — `ADBE Vector Star Outer Roundess`.
- `TextDocument.characterRange` есть только с AE 24.3.
- Смена текста по времени — удерживаемые ключи документа: возьми `valueAtTime`, поменяй `text`, `setValueAtTime`.

## Видимость

- Ничего не видно раньше своего времени: `inPoint` слоя = момент появления. Обрезка 100 % или прозрачность 100 % без ключа видны с первого кадра.
- Элемент, который ссылается на цель (`target`), не живёт дольше цели.
- Слои-фигуры не вращаются в 3D.

## Движение

- Свои ключи — только с кривыми движения базы (`tokens.motion`): никаких линейных и HOLD без причины.
- Ни одна фаза не короче 4 кадров, два ключа одного свойства не ставятся в один момент.
- Отскок продолжает скорость прихода, а не стартует после остановки: пружину бери из `move`/`appear` базы.
- Появления, уходы и движения — через блоки базы (`appear`, `move`), если они это умеют.

## Тяжесть

- Ключи только в моменты событий; ключи на каждый кадр и тяжёлые выражения (`wiggle` на десятках слоёв) делают композицию неподъёмной.
- Слоёв мало: один слой фигуры на элемент, группы внутри него, а не слой на каждую деталь.
- Демо больше 2–3 приёмов делится на части (`block_lab.py part`): одна большая композиция тормозит AE.
