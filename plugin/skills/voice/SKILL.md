description: Озвучивает текст автора его голосом в ElevenLabs: расставляет разрешённые теги интонации, генерирует запись с EQ. Отдельная команда автора, этап voice конвейера.
argument-hint: "<папка видео> <фрагмент> [текст]"

Автор запросил озвучку: $ARGUMENTS. Этап ведёшь ты сам. Ниже `S` — `${CLAUDE_PLUGIN_ROOT}/scripts`.

Генерация тратит кредиты ElevenLabs: запрос уходит только после «да» автора на текст с тегами.

1. **Состояние.** `python3 S/pipeline.py next <видео> <фрагмент>` → JSON с этапом `voice`. Фрагмента ещё нет — сначала `pipeline.py init <видео> <фрагмент> --from-text`. Этап `voice` пропущен (у фрагмента есть запись) — скажи об этом автору и ничего не генерируй.
2. **`start voice`** → JSON без «Отказ».
3. **Сырой текст.** Сохрани текст автора как есть в `<фрагмент>.script.txt`. Ни одного слова в нём не меняй.
4. **Пометки для анимации.** В круглых скобках автор может писать, что показать: «Возьмём массив (массив из пяти ячеек появляется)». Голос их не читает, а режиссёр плана получает. Автор может сказать об этом прямо, но и без его слов скобки с описанием показа — это пометки.
   - `python3 S/voice.py split <фрагмент>.script.txt --spoken <фрагмент>.spoken.txt --directions <фрагмент>.directions.json --video <видео>` → список «пометка перед словом N (после «…»): …» и текст без пометок. Пометкой скрипт считает скобки после пробела или в начале строки; формула вида `O(1)` пометкой не считается.
   - Просмотри список. Если в скобках оказалась часть речи, а не описание показа («(то есть быстро)»), верни её в `spoken.txt` и убери из `directions.json`. Если пометка без скобок явно описывает показ, а не речь, не озвучивай её: убери из `spoken.txt` и добавь в `directions.json` с номером слова. Сомневаешься — спроси автора на шаге 7.
5. **Теги.** Сделай `<фрагмент>.voice.txt` из `<фрагмент>.spoken.txt`: тот же текст, по одной фразе или мысли на строку, в начале строки при необходимости теги в квадратных скобках через запятую.
   - Разрешены только теги из настройки `voice.allowed_tags`, когда какой ставить — `voice.tag_hints` (`python3 S/settings.py get voice.tag_hints --video <видео>`). Другие теги не придумывай. Строка без тега звучит нейтрально.
   - Слова, порядок и смысл не меняй. Можно только разбить на строки и добавить «...» для паузы внутри фразы.
   - **Формулы и символы пиши так, как они произносятся:** голос читает их буквально («O(1)» звучит как «О в скобках один»). Готовые произношения — в `voice.spoken_forms` (`python3 S/settings.py get voice.spoken_forms --video <видео>`), бери их. Для формулы, которой там нет, предложи произношение и отметь его автору на шаге 7. Если автор захочет закрепить его, это запись в его личные настройки — только по его «да».

   Образец формата:
   ```text
   [slightly faster] Эта функция состоит из нескольких действий... и каждое из них выполняется за O(1).
   [thoughtful, short pause] Мы увидели важное свойство:
   [slightly faster, emphasized] сумма константных единиц... всегда равна константной единице.
   ```
6. **Проверка.** `python3 S/voice.py check <фрагмент>.voice.txt --video <видео>` → «Текст в порядке». Ошибка про тег — исправь тег. Ошибка «голос прочтёт буквально» — запиши формулу словами (подсказка в тексте ошибки). Повтори проверку.
7. **Вопрос автору.** Покажи текст с тегами целиком, отдельно перечисли формулы, которые ты записал словами, и пометки для анимации, которые голос не прочтёт. Спроси: «Озвучиваем?». Правки автора внеси в `voice.txt` или `directions.json` и повтори шаг 6.
8. **Генерация** после явного «да»: `python3 S/voice.py generate <фрагмент>.voice.txt --out <фрагмент>.wav --raw <фрагмент>.voice_raw.wav --video <видео>` → «Готово: …». Прошлый дубль скрипт сам сохраняет как `<фрагмент>.take<N>.wav`.
   - «Отказ: Нет ключа…» — покажи автору команду из текста ошибки, ключ сам не проси.
   - «Отказ: ElevenLabs 401 … permission» — у ключа не хватает прав: Text to Speech (Access), Voices (Read), Models (Access).
   - Любая другая ошибка — покажи её текст автору, обходной путь не ищи.
9. **`done voice`** → JSON. Скажи автору, где файл, и дай команду прослушать: `afplay <фрагмент>.wav`. Как звучит, решает только он.
10. **Решение автора.** «Да» → `approve voice`, дальше этап транскрипта. Правка → измени `voice.txt` (или только теги), снова шаги 6–9. Пометки из `directions.json` после транскрипта получит режиссёр плана.

Следующая команда: `/ae-video:transcript` (в других моделях `brief.py transcript <видео> <фрагмент>`).
