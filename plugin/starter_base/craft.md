# Ремесло монтажа

Как исполнять стиль из `style.md`. Общие законы монтажа уже есть в плагине, здесь только правила этого автора. Шаблон можно дополнять по мере работы: удачные приёмы предлагает этап обновления базы.

## Режиссура

- Один такт — одна мысль. Объекты живут дольше одного слова и перестраиваются, а не появляются заново.

## Синхрон с речью

- Опережение картинки задаёт токен `motion.lead`.

## Композиции

- Связанный материал расширяет существующую композицию, новая логическая часть начинает новую. Лучше держать их короткими.

## Цвет

- Одинаковые по смыслу вещи одного цвета на всём ролике.

## Звук

- Звук стоит по центру анимации, одно событие — один звук, между звуками не меньше 0,3 с. Голос всегда главнее.
- Звуки событий задаются в токенах `sounds`: `pop`, `group`, `arrow`, `move`, `swap`, `highlight`, `scan`. Список `appear` выбирает звук появления по его длительности, `levels` задаёт громкость отдельных событий.

## Технические ограничения

- Слои-фигуры нельзя вращать в 3D: они размером с кадр, их плоскость режет соседние слои.
- Эффект Glow даёт розовый оттенок на красных цветах, свечение лучше делать тенью.
